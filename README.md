# Portfolio — M. Marcheterre

Portfolio personnel professionnel en HTML/CSS/JS vanilla.

## Structure

```
portfolio/
├── index.html    # Structure de la page
├── style.css     # Styles (CSS custom properties, responsive)
└── script.js     # Interactions (navbar mobile, animations scroll)
```

## Sections

- **Hero** — Présentation avec boutons d'action
- **À propos** — Texte + informations de contact
- **Compétences** — Grille par catégories
- **Expérience** — Timeline verticale
- **Projets** — Cartes avec liens GitHub/Demo
- **Contact** — Formulaire + réseaux sociaux

## Déploiement GitHub Pages

1. Aller dans **Settings → Pages**
2. Source : `main` branch, dossier `/` (root)
3. Ton portfolio sera accessible sur `https://mmarcheterre.github.io/portfolio`
